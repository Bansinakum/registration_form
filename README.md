# Project 1 — Registration Form Validation

## Run
1. Open `index.html` in Chrome/Edge.
2. Fill in the form and click **Create account**.
3. Try invalid values to see JavaScript validation messages.

## Validation
- Name is required (minimum 2 characters).
- Email format is checked.
- Mobile number must contain 10 digits.
- Blood group is required.
- Password must be at least 8 characters.
- Confirm password must match.
- Consent checkbox is required.

Note: This is a front-end validation task. It does not save registrations to a database or create real accounts.
